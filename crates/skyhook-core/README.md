# Skyhook Core

`skyhook-agent-core` is the reusable runtime behind the `skyhook-agent` command-line
package. Its Rust library crate is named `skyhook`.

The core provides provider-neutral model connections, supervised tools and jobs,
persistent sessions, child agents, and embedded JavaScript orchestration.
